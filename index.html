Token de acesso

O OpenChat não usa conta. Informe o Bearer token exibido no fim da instalação do install_opencode.sh. O valor fica salvo apenas neste navegador e pode ser removido a qualquer momento.

Testar a API por curl 
curl -H "Authorization: Bearer $TOKEN" \
  https://api.projetosdinamicos.com.br/llm/v1/models

curl -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Olá"}]}' \
  https://api.projetosdinamicos.com.br/llm/v1/chat/completions

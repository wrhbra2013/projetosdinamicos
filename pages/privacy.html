Politica de Privacidade

Ultima atualizacao:

1. Sobre a Extensao

O Podcast Search & Player e uma extensao gratuita para o navegador Google Chrome que permite buscar e reproduzir podcasts de multiplas fontes (YouTube, Spotify, Archive.org, Podcast Index e feeds RSS).

2. Dados Coletados

A extensao coleta os seguintes dados:

  • Dados de busca: Termos de busca inseridos pelo usuario sao processados localmente e enviados apenas as APIs das fontes selecionadas (YouTube Data API, Spotify Web API, etc.). Nao armazenamos seus termos de busca.
  • Configuracoes locais: Preferencias do usuario (chaves de API, feeds RSS salvos, favoritos, volume) sao armazenadas localmente no navegador usando chrome.storage.local. Esses dados nunca sao enviados para servidores externos.
  • Dados de uso: A extensao nao coleta metricas de uso, analytics ou dados de navegacao.

3. Uso de Dados

Os dados coletados sao utilizados exclusivamente para:

  • Executar buscas nas APIs de podcast selecionadas pelo usuario.
  • Armazenar configuracoes e preferencias do usuario localmente.
  • Permitir o save de episodios no SidPositivo (quando configurado pelo usuario).

4. Compartilhamento de Dados

A extensao NAO compartilha dados pessoais com terceiros. As unicas comunicacoes externas sao:

  • Requisicoes as APIs de podcast (YouTube, Spotify, etc.) feitas pelo usuario.
  • Requisicoes ao servico SidPositivo (quando o usuario configura ativamente).

5. Armazenamento de Dados

Todas as configuracoes e dados do usuario sao armazenados localmente no navegador using chrome.storage.local. Esses dados:

  • Ficam apenas no dispositivo do usuario.
  • Nao sao sincronizados com servidores externos.
  • Sao excluidos quando o usuario remove a extensao.

6. Seguranca

A extensao nao utiliza cookies, tracking ou pixels de rastreamento. Nao ha coleta de dados pessoais identificaveis (PII).

7. Menores de Idade

A extensao nao e direcionada a menores de 13 anos e nao coleta dados de menores de intencionalmente.

8. Alteracoes nesta Politica

Esta politica pode ser atualizada periodicamente. As alteracoes serao publicadas nesta pagina com a data de atualizacao.

9. Contato

Em caso de duvidas sobre esta politica de privacidade, entre em contato:

  • Email: contato@projetosdinamicos.com.br
  • Site: www.projetosdinamicos.com.br

10. Conformidade

Esta extensao esta em conformidade com:

  • Termos de Servico da Chrome Web Store.
  • Politica de Privacidade do Google.
  • Lei Geral de Protecao de Dados (LGPD) do Brasil.
